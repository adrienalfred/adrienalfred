## 🚀 Featured Project

### [conteneur-lite](https://github.com/adrienalfred/conteneur-lite)
Lightweight container runtime built on Linux primitives — written in Go.
No daemon, no dependencies, single binary of 3.4MB.

| Metric | conteneur-lite | Docker |
|---|---|---|
| Startup time | 505ms | 285ms |
| Memory at rest | 1704 kB | 2280 kB |
| Binary size | 3.4 MB | 80 MB |
| Dependencies | 0 | Many |

> Built with Linux namespaces, cgroups v2, and Go — from scratch.
